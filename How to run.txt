After unzip:

Terminal 1 – Backend

cd backend (or your directory that store the frontend folder)
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload

Back end will run on: http://localhost:8000

--------------------------------------------------

Terminal 2 – Frontend

cd frontend (or your directory that store the frontend folder)
npm install
npm run dev

Open web and enter:http://localhost:5173
